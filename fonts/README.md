# Fonts

The site is set up for **ABC Monument Grotesk Mono** (by Dinamo). It is a paid font, so it is not included here.

If you buy a web licence at https://abcdinamo.com, put these two files in this folder:

- `ABCMonumentGroteskMonoVariable.woff2`
- `ABCMonumentGroteskMonoVariable-Italic.woff2`

If your files have different names, change the `url(...)` lines at the top of `styles.css`.

Until the files are here, the site uses **Geist Mono**, a free font from Google Fonts.
